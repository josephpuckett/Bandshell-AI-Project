How to use this app

  1. Create an event. Click + New Event and fill in the details (title, dates, description, image). The everyday info like venue and organizer comes from ⚙️ Settings.
  2. Add a website. Click + Website to tell the app where events should go — e.g. an Eventbrite page or another organization's calendar form. You do this once per website.
  3. Set each website up (one time). Open a website and click Set up this website. An AI fills the site's form in a browser window. Watch it, check the result, then Approve (or Reject with a note so it can fix it).
  4. Review and submit. The AI saves a routine for that website. From then on, adding an event to it runs the saved routine — you review the filled form in the browser and submit it yourself. Eventbrite sites send events straight to Eventbrite as drafts for you to publish.

Tip: hovering over the ? markers next to fields explains what each field does.
